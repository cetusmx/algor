## Overview

**Page Purpose:** Servir como un índice de proyectos reales resueltos por algor, estructurado por el "problema operativo" en lugar de la tecnología, para facilitar que el usuario encuentre su "Bala de Plata".

**Entry Points:**
- Clic desde el Home en "Explorar Casos de Estudio" o en una tarjeta de dolor específico.

**User Mental State:**
Urgencia por validar experiencia. Sabe lo que quiere, así que escaneará la página buscando palabras clave como "ERP", "Legacy", "API", etc.

**Main User Goal:** Filtrar problemas operativos y hallar un caso de estudio idéntico a su desafío técnico ("la bala de plata").

**Business Goal:** Evidenciar expertise transversal e incitar al usuario a profundizar en un caso concreto.

**URL/Route:** `/casos-de-uso`

## Phase 4: UI Specifications & Component Mapping

### Global Layout & Theming
- **Background:** Dark slate `#0f172a` (consistency with Home Page).
- **Typography:** Inter (sans-serif) for body, Space Grotesk or JetBrains Mono for technical highlights/tags.
- **Grid System:** CSS Grid for the Curated List, ensuring responsive collapse from desktop to mobile.

### 2. Page Header
- **Layout:** Centered content with maximum width constraint (`max-w-3xl`) to ensure readability.
- **Typography:** `H1` using a bold, large typeface (`text-4xl md:text-5xl`), text color `white`.
- **Spacing:** Generous padding top and bottom (`py-16 md:py-24`).
- **Accent:** Subtle gradient or tech-inspired accent line below the title.

### 3. Curated Case Studies List
- **Component:** `CaseStudyCard`
- **Layout:** Vertical asymmetrical list or a 2-column grid (`grid-cols-1 md:grid-cols-2 gap-8`).
- **Visuals:** 
  - **Card Background:** Glassmorphism effect (`bg-white/5 backdrop-blur-sm border border-white/10`).
  - **Hover State:** `hover:-translate-y-1 hover:border-orange-500/50 transition-all duration-300`.
- **Content Mapping (Card):**
  - **Tag/Badge:** Small capsule, uppercase, mono-spaced font (`text-orange-400 bg-orange-400/10 px-3 py-1 rounded-full text-xs`).
  - **Title:** `H3` (`text-xl font-bold text-white mt-4`).
  - **Excerpt:** Secondary text (`text-slate-300 mt-2 line-clamp-3`).
  - **Action:** "Ver caso completo →" (`text-orange-500 font-medium group-hover:translate-x-2 transition-transform`).

### Responsive Behavior
- **Mobile (< 768px):** Cards stack vertically, typography scales down slightly.
- **Tablet/Desktop (≥ 768px):** 2-column grid to maximize screen real estate, maintaining the curated, high-end technical feel.
