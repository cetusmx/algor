# Primary Button [btn-001]

**Type:** Interactive
**Category:** Action
**Purpose:** Trigger main actions like "Agendar Reunión"

---

## Overview

The Primary Button uses the deep slate (`primary-base`) color on the light background. It feels grounded, serious, and highly authoritative.

---

## Variants

- **primary-light** - Fondo Deep Slate (`#0f172a`), texto blanco. (Regla: Usar SOLO sobre fondos blancos/claros).
- **primary-dark** - Fondo Naranja Industrial Sólido (`#FF5100`), texto blanco. (Regla: Usar SOLO sobre fondos muy oscuros como el Hero para resaltar como un faro).
- **secondary** - Outline only, for less important actions.
- **ghost** - Text only.

---

## States

**Default (Light Context):** Deep Slate (`#0f172a`) background
**Default (Dark Context):** Industrial Orange (`#FF5100`) background
**Hover:** Oscurecimiento o aclaramiento ligero del tono base.
**Focus:** Anillo de enfoque Naranja Industrial (`#FF5100`) para el botón Slate, o anillo blanco para el botón Naranja.

---

## Styling

### Visual Properties

**Size:** medium (h-10, px-4)
**Shape:** rounded (border-radius: 6px / radius-md)
**Colors:**
- Background: `primary-base` (#0f172a)
- Text: `#ffffff`
- Border: none

**Typography:**
- Font Family: 'Inter'
- Font size: 14px
- Font weight: 600 (Semibold)
