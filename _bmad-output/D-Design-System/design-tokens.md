# Design Tokens

**Status:** Draft

Design tokens will be extracted as components are added to the design system.

## Token Categories

### Colors
**Backgrounds (Enterprise Light):**
- `bg-base`: #ffffff (Pure White)
- `bg-surface`: #f8fafc (Slightly cool off-white for cards, less muddy than #f4f4f4)
- `bg-surface-hover`: #f1f5f9

**Brand / Primary (Deep Slate):**
- `primary-base`: #0f172a (Deep Slate - For primary buttons and main accents)
- `primary-hover`: #1e293b
- `primary-active`: #334155

**Brand / Secondary (Tech Accent):**
- `accent-tech`: #FF5100 (Industrial Orange - Used sparingly for links, focus rings, hover borders, or subtle tech details)

**Text:**
- `text-primary`: #0f172a (Deep Slate - very high contrast on white)
- `text-secondary`: #475569 (Slate 600)

**Semantic:**
- `success`: #059669
- `error`: #dc2626
- `warning`: #d97706

### Typography
- **Font Family (Base):** 'Inter', system-ui, sans-serif
- **Base Size:** 16px
- **Heading Weights:** 600 (Semibold), 700 (Bold)

### Spacing & Layout
- `spacing-xs`: 4px
- `spacing-sm`: 8px
- `spacing-md`: 16px
- `spacing-lg`: 24px

### Effects (Border Radius & Shadows)
- `radius-sm`: 4px
- `radius-md`: 6px (Standard for buttons and inputs)
- `radius-lg`: 12px (For cards)
- `shadow-subtle`: 0 1px 3px rgba(0,0,0,0.05), 0 1px 2px rgba(0,0,0,0.1)
